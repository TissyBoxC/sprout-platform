# 付费与订单

家长端的商业化模块，负责套餐展示、下单、支付、订单记录与退款申请。

- **domain**：`Money` 金额值类型只保存整数「分」，拒绝小数输入；`BillingPlan`、
  `BillingOrder`、`BillingConsent` 分别对应套餐、订单与消费授权。
- **data**：`BillingApi` 直接解析后端返回的整数分，业务状态（支付未开放、
  缺少消费同意）转成独立异常，不把后端原文交给界面。
- **application**：`BillingPlansController`、`BillingOrdersController`、
  `BillingConsentController` 用请求生成号丢弃陈旧结果，网络抖动时保留上一次
  成功的数据。
- **presentation**：套餐列表、结算、订单记录、消费条款四个页面，金额一律显示
  `¥X.XX`，不出现小数以外的写法。

## 孩子安全约束

购买必须由家长完成：

1. 没有有效消费同意时，结算页只展示同意步骤，不会创建订单。
2. 创建订单前先检查同意状态；服务端仍拒绝时回到同意步骤。
3. 「确认支付」会再次弹出金额确认，家长确认后才发起支付。

支付渠道尚未接入时，后端会返回明确的「未开放」结果，页面显示
「支付功能尚未开放，请稍后再试」，订单保留为待支付。
